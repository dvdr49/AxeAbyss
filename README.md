# AXE ABYSS — Website

A black / white / gray, minimal underground artist website.

## Files
- `index.html` — page structure and content
- `styles.css` — complete responsive design
- `script.js` — tiny interaction layer
- `assets/swag-pfp.jpg` — current Axe Abyss Instagram PFP
- `assets/the-abyss.svg` — editable debut-album artwork
- `assets/favicon.svg` — favicon

## Publish with GitHub Pages
1. Create a GitHub repository (for example `axe-abyss`).
2. Upload all files while keeping the `assets/` folder.
3. GitHub → Settings → Pages → Deploy from branch → `main` / root.
4. Replace the `#` links in `index.html` with your real Spotify, Instagram, YouTube, etc.
5. If you buy a custom domain later, add it in GitHub Pages → Custom domain.

## Important
The site currently uses Google Fonts from `fonts.googleapis.com`. If you want a completely self-contained/offline version, download and locally host the fonts later.
